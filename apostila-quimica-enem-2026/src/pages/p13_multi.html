2 · Para cada OTem C=O? Olhe os vizinhos do C (H, C, OH, OR). Sem C=O: OH = álcool ou fenol; entre 2 C = éter.

3 · Para cada NLigado a C=O = amida. Só a C saturado = amina. C≡N = nitrila. Com O,O = nitro.

{{icon:alert}} Erros que mais derrubam
1. OH ligado ao anel é fenol (não álcool). 2. C=O com O–C ao lado é éster; O entre dois C sem C=O é éter. 3. N ao lado de C=O é amida, não amina. 4. O anel aromático não é uma “função” separada nas provas de grupos funcionais: é parte do esqueleto (hidrocarboneto aromático).
{{icon:func}} Por que isso importa
As funções determinam propriedades: o fenol e o ácido carboxílico da aspirina (quando presentes) dão acidez; amina é básica; OH, COOH e N–H fazem ligações de hidrogênio (maior solubilidade em água); o anel aromático e cadeias longas são apolares (lipofílicos).
